# Rakesh M — Portfolio

A responsive dark glassmorphism portfolio built as a simple static website.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive styles
- `script.js` — mobile menu and reveal animations
- `assets/profile.png` — profile photo

## GitHub Pages
1. Create a GitHub repository, for example `rakesh-portfolio`.
2. Upload all files and the `assets` folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.
